# HissyHiss

HissyHiss is a browser-based Snake game made with plain HTML, CSS and JavaScript. The idea is simple: eat the food, grow longer, don't run into yourself, and try not to completely ruin your score.

## What it has

* Classic Snake gameplay
* Keyboard controls
* Food spawning
* Snake growth
* Score tracking
* Increasing difficulty as the game goes on
* Collision detection
* Game over state
* Restart functionality
* Simple responsive game layout
* Custom UI and styling

## How to play

Open `snake.html` in your browser.

Use the arrow keys to move the snake.

Eat the food to increase your score and make the snake longer.

Don't hit the walls or your own body because that is, unfortunately, how the game ends.

Try to survive for as long as possible and beat your previous score.

## Controls
Well thats the basic - wasd or use the arrow keys for pc or laptops , and for the androids just glide.

## Tech used

Too simple.

* HTML for the structure
* CSS for the UI and styling
* JavaScript for the actual game logic

## Running it locally

Clone the repository:

```bash
git clone https://github.com/mehroofsaba/HissyHiss.git
```

Go into the project:

```bash
cd HissyHiss
```

Then open:

```text
snake.html
```

in your browser.

There is no build process or installation required.
